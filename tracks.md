# Grok Bot Hackathon Austin: tracks (Oct 19, 2026)
Pick one of three tracks; mixing them is fine.
1. **Rebuild a tool you pay for.** Nail the one loop people pay for.
2. **Build for the bot economy.** The user is a bot: an MCP server, a skill pack, or a connector.
3. **The one person company.** Bots run sales, support and ops for one founder.

Tip from the organizers: set up a spec bot, a reviewer bot and a release bot first, then build.
Build runs 5:30 to 8:30 PM CT, dinner at 6:30, winner named at 9:45.

**Garage Sale's track:** 3, the one person company (bots run sales and support for a solo seller). It also touches track 1, as a replacement for paid listing and reselling tools.
